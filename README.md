# Promo Pal

Por gentileza, crie um site hub completo para afiliado.

Home: 

1. Foto, nome (título) e descrição 

2. Deve exibir grade com os ícones e nome das categorias, o nome deve ser em fonte pequena (mas legível) abaixo do ícone 

Categoria: (ao clicar em algum ícone)

1. Exibir título (nome da categoria) e descrição 

2. Vitrine de lojas afiliadas, com nome e botão para ver cupons e acessar loja 

3.  Ao clicar em ver cupons, abrir modal/contêiner com cupom, botão de copiar e descrição (opcional)

4. Ao clicar em acessar loja, ser redirecionado pro link definido 

Rodapé:

1. Ícones de redes (ao clicar, abrir link)

2. Termos e Privacidade

Admin:

1. Adicionar, editar, ativar/desativar e excluir categoria. Informar se a categoria é restrita ou não.

2. Adicionar loja, informando nome, selecionando categorias e informar se tem cupom ou não 

2.1. Se tiver cupom, disponibilizar campos para adicionar cupons e descrição/regras

3. Adicionar ou excluir "rede social", escolhendo o ícone na biblioteca, informando nome e informando o link 

4. Editar texto do Termos e Privacidade 

5. Ter o Vini, assistente de IA que pode executar todas as ações do ADMIN 

Extras:

1. Crie uma biblioteca de ícones 3D gradiente para as categorias (deve ter opção para inúmeros tipos de negócios (roupa, cosméticos, perfumes, suplementos, brinquedo, etc) e inclusive, internet, chips telefônico, maquininha de cartão, conta bancária e até bet

2. Crie ícones 3D para o Vini (estilo jovem atual, cabelo penteado de lado)

3. Se a loja tem cupom, exibir na vitrine, na respectiva loja, um ícone de cupom com algum efeito visual 

4. Se a loja não tiver cupom, o botão de ver cupom, fica cinza inacessível 

5. Se a categoria for restrita, ao clicar nela, abrir modal que pede a idade (menor de 18 anos, acesso bloqueado, 18 ou mais, abre normalmente com aviso definido pelo ADMIN no topo)

---

Por favor, crie um site moderno e responsivo pronto para ser hospedado no Vercel (o painel ADMIN sempre usarei no site hospedado no Lovable).

ADMIN loga com usuário e senha (crie um acesso e me passe as credenciais, permita alteração de senha no painel) adicione botão que leva pro painel ADMIN 

O ícone do site deve ser ícone de cupom de desconto 3D e a prévia ser captura de tela da home
